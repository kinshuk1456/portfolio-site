Local Authoring Helper

This is a local-only helper for generating JSON/Markdown files. It does not log in, does not write to any server, and is safe to keep out of production.

Recommended (safer + faster): use the CLI

In your terminal:

cd portfolio-site
npm run author
npm run build
npm run preview
