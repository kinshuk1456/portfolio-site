# Pricing Notes

Pricing is mostly communication.

## The framework
- **Value metric**: what scales with value (seats, usage, outcomes)
- **Packaging**: what goes into each tier
- **Paywall**: the moment the user *feels* the upgrade

## Practical rules
- Don’t create tiers for internal org structure—create tiers for customer progress.
- Prefer *one* primary upgrade path.
- Use add-ons when value is optional and independent.

## Example
A starter plan makes the product usable. The middle plan removes friction. The top plan removes risk.

```text
Starter  = usable
Growth   = faster
Scale    = safer
```
