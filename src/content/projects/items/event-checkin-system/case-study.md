# Event Check-In Product System (QR + Python) — Case Study

## Context
Event operations needed a reliable check-in flow and real-time room-level visibility—without manual tallies.

## Problem
- Slow onboarding/check-in created bottlenecks
- Stakeholders needed real-time participant tracking across 30+ rooms
- Reporting required too much manual reconciliation

## Approach
- Gathered requirements and mapped the end-to-end check-in journey
- Implemented a QR-based onboarding/check-in flow
- Built a lightweight tracking store and a dashboard view for real-time visibility and reporting

## Outcome
A faster check-in experience with clearer, real-time operational visibility and simpler reporting.
