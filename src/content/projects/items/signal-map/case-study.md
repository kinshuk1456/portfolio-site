# Signal Map

## What it is
Signal Map is a lightweight analytics dashboard designed for **weekly decision-making** — not vanity metrics.

## The problem
- Data existed, but it was split across tools
- Weekly roadmap discussions started with *"what do we even know?"*
- Metrics definitions weren’t consistent, so debates turned into opinions

## Approach
- Defined a small set of **actionable signals** (activation, retention proxy, core action volume)
- Designed a single-page view with **opinionated defaults** and a clear narrative (health → drivers → details)
- Set up a refresh pipeline so meetings start with consistent numbers

## Outcome
- Meetings shifted from collecting data to making decisions
- The team aligned around shared definitions and a small, stable KPI set
- The dashboard stayed usable because it stayed simple
