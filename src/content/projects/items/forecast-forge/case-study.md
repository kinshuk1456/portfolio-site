# Forecast Forge — Case Study

## Goal
Create a forecasting + scenario tool that helps teams make planning decisions with **shared assumptions** and **visible risk**.

## What made it hard
- Different stakeholders optimized for different constraints
- Inputs changed weekly
- Existing spreadsheets were opaque and brittle

## Approach
- Built a baseline forecast from a few key drivers
- Added a scenario layer (best/base/worst) with documented assumptions
- Included sensitivity checks so stakeholders could see which inputs mattered most

## Outcome
The model made planning discussions faster and more productive because disagreements moved from "which number is right" to "which assumption do we believe".
